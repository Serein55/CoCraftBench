# Mindcraft 本机部署

本目录用于 NLP 课程项目：Minecraft Java 版 1.21.6、一个名为 `andy` 的机器人、书生 API 网关中的 DeepSeek 模型。

## 使用顺序

1. 当前 API Key 已配置。以后更换时，双击本目录的 `configure-key.cmd`，粘贴当前服务的 API Key 并回车。输入不会显示；密钥仅写入 `mindcraft/keys.json`，该文件已被项目的 Git 忽略规则排除。不要把密钥文件公开。
2. 用你现有的 Minecraft 启动器安装并启动 **Java 版 1.21.6**。先使用原版、和平难度和小型测试世界。
3. 进入世界后按 Esc → 对局域网开放 → 端口填写 **55916**。每次重新打开世界后都要重新开放 LAN。
4. 双击 `start-mindcraft.cmd`。启动脚本会先检查依赖、Key 是否已填写以及游戏端口，然后启动机器人。机器人名为 **andy**。
5. 在游戏中依次测试：`你好，请用中文回答`、`告诉我你的位置和背包物品`、`走到我旁边`、`收集4个橡木原木`、`把橡木原木交给我`。每次等待上一个动作完成。
6. 在启动终端按 Ctrl+C 停止程序。

如果管理端口 8080 已在使用，脚本会避免重复启动。现有 Mindcraft 管理界面为 http://localhost:8080 。

## 配置位置

| 文件 | 用途 |
|---|---|
| `mindcraft/keys.json` | 当前网关密钥存于 `OPENAI_API_KEY`；该字段名表示 OpenAI 兼容协议，不要求购买 OpenAI 服务 |
| `mindcraft/andy.json` | 模型名称、API 地址、请求参数和机器人名字 |
| `mindcraft/settings.js` | 游戏版本、地址、端口、功能开关 |
| `runtime/node-v22.23.4-win-x64/` | 仅供此项目使用的 Node 22，不修改系统 Node |

当前使用 `deepseek-v4.1-flash-1017`，OpenAI 兼容地址为 `https://discovery-api.intern-ai.org.cn/v1`。模型 ID 已通过该服务的实际模型列表确认。保留原 DeepSeek 官方密钥，但当前聊天不会使用它。

关闭思考模式、视觉、语音和动态代码生成。`embedding=false` 禁止自动向量请求，避免自定义网关密钥被用于默认 OpenAI 向量地址。示例选择使用词语匹配。

`max_commands=3` 只限制一次连续响应中的命令数量，不能作为费用上限。每次模型请求都可能消耗服务额度。

`language=en` 在这里用于跳过额外的 Google 翻译；初始化提示要求 DeepSeek 直接用中文交流。保留英文命令格式。

`auth=offline` 面向本机 LAN 测试。连接启用正版验证的服务器时，需要改为 `microsoft` 并登录相应的 Minecraft 账号。

## 自检

在本目录打开 PowerShell：

```powershell
.\start-mindcraft.cmd --check
```

这里只检查本地项目和端口，不调用 API，也不会显示 Key。端口能连通不代表已经完成 Minecraft 登录。

要单独确认 Key、余额、模型是否可用，可执行下面命令，会产生一次很小的 API 请求：

```powershell
.\start-mindcraft.cmd --api-test
```

## 常见问题

- 提示尚未填写 Key：运行 `configure-key.cmd`，确认当前服务额度可用。
- 提示游戏端口未开放：确认游戏已进入世界、开放 LAN、端口为 55916。
- 版本不匹配：确认启动的是 Java 版 1.21.6，且没有改变玩法或协议的整合包。
- 当前明确关闭向量请求，示例选择使用词语匹配。
- API 报错：先运行 `--api-test`，检查 Key、余额、模型名和网络。
- 能聊天但采集失败：先在平坦、附近有树的测试环境中尝试，检查工具、地形和物品条件。
